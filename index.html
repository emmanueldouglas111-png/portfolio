✓ Secure front-end principles I build by

    
    
      
  • Treat all input as untrusted. Render user-provided text with textContent, not innerHTML, to avoid cross-site scripting (XSS).
    • 
      
  • Keep secrets off the client. API keys never go in front-end code; they belong in server-side environment variables.
    • 
      
  • Ship over HTTPS. Hosting on platforms like Vercel serves sites over HTTPS by default.
    • 
      
  • Least privilege and minimal dependencies. Fewer third-party scripts means a smaller attack surface.

03 / completed project
Mama Joy Restaurants

  

    

      

      
Great Nigerian Food. One Conversation Away.

      

    

    

      
A responsive restaurant website with an AI voice-assistant concept. I recreated it from a screen recording, matching its green-and-gold look, serif headings, filterable menu and live-conversation panel.

      
What it includes

      
    
        
  • Sticky navigation with active-section highlighting and smooth scrolling
    • 
        
  • Hero section with calls to action and key stats
    • 
        
  • Menu grid with category filters, spice and bestseller tags, and photo fallbacks
    • 
        
  • "Try It Yourself" prompt cards that drive a scripted live-transcript demo
    • 
        
  • Mobile-friendly layout and keyboard focus styles
    • 
      

      
The challenge

      
A restaurant needs more than a social media page: visitors want to see the food, trust the place and know how to order, usually on a phone. I set out to build a fast, food-first site that also shows a modern idea, an AI voice assistant that takes orders through conversation.

      
My approach

      
I chose plain HTML, CSS and JavaScript on purpose. A restaurant page does not need a framework, and fewer dependencies mean faster loads and less to break. The design leads with photography and a clear green-and-gold identity, and the assistant is a scripted demo so the page stays safe and private.

      
Problems I solved

      
    
        
  • Broken images: missing or misnamed files showed raw alt text, so I added photo fallbacks that keep the layout intact.
    • 
        
  • Layout overflow: the page scrolled sideways on some screens. I traced it to elements wider than the viewport and fixed it with containment and flexible sizing.
    • 
        
  • Deployment bugs: file names that worked on Windows failed on Vercel because its servers treat Script.js and script.js as different files. I now keep names and paths consistent and lowercase.
    • 
      

      
What I learned

      
Responsive layout debugging, careful asset handling, and a repeatable Git → GitHub → Vercel release routine where every push redeploys automatically.

      
Built with

      
  • HTML5
  • CSS3
  • Vanilla JavaScript
  • Google Fonts
  • Git & GitHub
  • Vercel

      
Security notes. The chat transcript renders text with textContent, the page contains no API keys, and the demo replies are scripted, so no user data leaves the browser.

Marketing Business Project

    

    

      
Marketing Business Project

      
A landing page for a marketing business, built with React, where clients can look up products and buy them. It is live on Vercel with the source on GitHub.

      
The challenge

      
A marketing business needs a landing page that explains what it offers and lets clients browse products and move toward buying without friction.

      
My approach

      
I built the page in React, splitting the interface into reusable components so products and sections are easy to add or change. Product listings are repeated, interactive UI, which is where React's component model and state handling help most. I also wanted to apply my React skills in a real, shipped project.

      
What it does today

      
    
        
  • Landing page presenting the business and its products
    • 
        
  • Product browsing with an Add to Cart button on every product
    • 
        
  • Shopping cart with quantity controls, remove, and a live total in naira
    • 
        
  • One-tap ordering through WhatsApp: the order, quantities and total are pre-written in the message to the seller
    • 
        
  • Multi-page navigation (Home, About, Contact, Cart) with React Router
    • 
        
  • Deployed on Vercel from GitHub, so every push updates the live site
    •
